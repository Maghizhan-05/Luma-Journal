# Screenshots

`share-card.png` is a real export from the app's client-side card renderer
(a Key Moment in the Portrait / Story size).

To add live app screenshots, run the app with seeded data and capture each
screen, then drop the PNGs here and reference them from the top-level `README.md`.

Suggested set (1280×800 desktop, or 390×844 mobile):

| File | Screen |
| --- | --- |
| `today.png` | `/app` — the daily journal board |
| `month.png` | `/app/month` — calendar |
| `year.png` | `/app/year` — streak heatmap |
| `analytics.png` | `/app/analytics` — charts + budgets |
| `moments.png` | `/app/moments` — search |
| `landing.png` | `/` — marketing page |

```bash
npm run dev
# then open http://localhost:3000 and capture each screen
```
